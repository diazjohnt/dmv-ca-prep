California DMV Practice Exam

Class C Knowledge Test

Every test is generated from the official 2025 California Driver’s Handbook (DL 600, revision 6/2025), in the format used by the DMV sample tests. Each question cites the handbook section it came from, and every incorrect answer shows the passage it was drawn from.

The official Class C knowledge test has 36 questions for applicants 18 and older, who must answer 30 correctly, and 46 questions for applicants under 18, who must answer 38 correctly. Both require roughly 83 percent.
